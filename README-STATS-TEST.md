# Δοκιμαστική έκδοση στατιστικών — Sports Live

## Ασφαλής δοκιμή

- Το `index.html` είναι το αρχικό αρχείο και δεν έχει τροποποιηθεί.
- Το `index-with-stats.html` είναι η ξεχωριστή δοκιμαστική έκδοση. Μπορεί να ανοιχτεί δίπλα στην αρχική και δεν την αντικαθιστά.
- Η ένδειξη στο κάτω μέρος είναι προσωρινά «Στατιστικά μη ρυθμισμένα». Δεν καταγράφεται ούτε αποστέλλεται κανένα δεδομένο.
- Το `PRESENCE_ENABLED` είναι `false` επίτηδες. Μην το ενεργοποιήσεις πριν δημιουργηθεί και ρυθμιστεί το backend και προστατευτεί το ιδιωτικό API.

## Τι απομένει για πραγματικά στατιστικά

1. Δημιουργία Cloudflare Pages/Worker και D1 database.
2. Endpoint heartbeat για τον αριθμό online και συγκεντρωτικά page views ανά ημέρα.
3. Προστατευμένη διαδρομή διαχειριστή με Cloudflare Access, επιτρέποντας αποκλειστικά το email του ιδιοκτήτη. Η προστασία πρέπει να καλύπτει τόσο τη σελίδα πάνελ όσο και κάθε API endpoint που επιστρέφει στατιστικά.
4. Έλεγχος λειτουργίας και επιβεβαίωση της πολιτικής διατήρησης δεδομένων πριν ενεργοποιηθεί η καταγραφή.

Δεν υπάρχουν κωδικοί, tokens ή email μέσα στα δοκιμαστικά αρχεία. Το δημόσιο repository δεν πρέπει να περιέχει secrets. Η δοκιμαστική έκδοση δεν είναι παραγωγικό analytics σύστημα και δεν έχει δημοσιευτεί.
